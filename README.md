# MLOps_Oops_Practice
This repo will contain Oops Practice self work

This repo contains code for a mini app as a part of oops practice - A simple Chat App - CHATBOOK!. 

The entire logic (Although very limited since this is for learning purpose only) is writtent in mini_Project.py file.

A streamlit front end is created where the actual code is borrowed from mini_project.py file and modified in streamlit style coding.

Run the app by executing cde from mini_project.py file to run application logic in console.

Run the streamlit frontend by executing code in Streamlit_app.py file.
